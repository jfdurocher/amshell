# amshell
An Apple Music shell/terminal display and controller.

![alt text](https://github.com/jfdurocher/amshell/blob/main/screenshot.png?raw=true)


## How to install

Download or clone the repo and run the `amshell.sh` file in your macOS Terminal. (macOS only; uses AppleScript.)
Install dependencies with Homebrew:

```bash
brew install jp2a jq
```

## How to use

| COMMAND  | CMD | DESCRIPTION                |
|----------|-----|----------------------------|
| play     | p   | Launches Music             |
| pause    | a   | Pause music                |
| next     | n   | Next song                  |
| previous | b   | Previous song              |
| quit     | q   | Exit script                |
